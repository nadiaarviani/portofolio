Penelitian Tugas Akhir

Pengolahan Data · Pelaporan

Prediksi Churn Rate Peserta Segmentasi Bukan Penerima Upah (BPU) Menggunakan Machine Learning

Penelitian untuk memperkirakan jumlah peserta yang berhenti membayar iuran (churn), sebagai dasar langkah mempertahankan kepesertaan.

Data kepesertaan dari 11 sheet Excel (294.993 baris) saya rapikan dan standarkan menjadi dataset mingguan periode 2016–2024. Dari dataset tersebut, saya membandingkan dua metode prediksi dan memilih yang hasilnya paling mendekati data sebenarnya. Hasil akhirnya berupa prediksi 4 minggu ke depan, sebuah dashboard, dan 3 rekomendasi untuk mempertahankan peserta, antara lain edukasi tatap muka dan peningkatan penggunaan pembayaran digital.
